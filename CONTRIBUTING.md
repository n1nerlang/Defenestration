## CONTRIBUTING
First off, thank you for checking out Defenestration OS! Taking a stand against telemetry and hardware-melting desktop environments is a team effort. 

Because Defenestration OS handles operations as **OS-as-Code**, you don't need a high-end rig or hours of free time to compile an entire operating system locally to contribute. You just modify the configuration blueprints, package rosters, or the native Rust engine, and let our GitHub Actions runners handle the heavy compilation.
